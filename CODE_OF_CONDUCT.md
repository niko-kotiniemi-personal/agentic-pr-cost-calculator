# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in its issues, pull requests and discussions is expected to meet it.

## Reporting

Report behaviour that breaks the code of conduct privately to the project's maintainer, [@niko-kotiniemi-personal](https://github.com/niko-kotiniemi-personal), through the contact on their GitHub profile. Reports are read by the maintainer only, and the reporter's identity is kept private.

## Enforcement

The maintainer decides on each report, and may correct, warn, suspend or ban, as the Contributor Covenant's enforcement guidelines describe.
